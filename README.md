<h1>What the frontend does</h1>
<h3>Sign in / register — Aadhar + password, 12-digit check before it hits the server, JWT kept in localStorage
Ballot — numbered candidate rows with a vote button and a lamp that lights on your choice; locks after voting and for admins
Results — live counts with bars, percentages and total turnout
Account — profile details and change password
Manage candidates — admin-only tab: add, edit, remove </h3>
